# US Bikeshare Data Analysis

## Project Overview
This project uses Python to explore bikeshare data for the New York City. It allows a user to filter the data by month and day and then calculates useful statistics about bike usage. The analysis identifies popular travel times, common stations and routes, trip durations, and available user information.

## How to Use the Project
1. Install Python 3, pandas, and NumPy.
2. Place bikeshare.py and new_york_city.csv in the same folder.
3. Open a terminal in the project folder.
4. Run python bikeshare.py
5. Follow the prompts to select a city, month, and day.

## Project Files
1. bikeshare.py - contains the Python code used to filter and analyze the bikeshare data.
2. new_yrk_city.csv - contains the bikeshare data and is excluded from Git tracking.
3. .gitignore - prevents the CSV data file from being uploaded to GitHub.
4. README.md - provides information and usage instructions for the project.
